# Credits und Lizenzen

## Grafik
Saemtliche Kacheln, Gebaeude, Figuren und Pokemon-Sprites werden zur Laufzeit aus eigenem Code erzeugt (`client/js/art/`). Sie stehen unter derselben Lizenz wie der restliche Code dieses Projekts.

Optional laedt `npm run sprites` die Original-Sprites aus Pokemon Platin ueber https://github.com/PokeAPI/sprites und die Trainerbilder ueber https://github.com/smogon/sprites in den lokalen, nicht versionierten Ordner `client/sprites/`. Diese Bilder sind Eigentum von Nintendo, Creatures Inc. und GAME FREAK inc. und sind nicht Teil dieses Repos.
